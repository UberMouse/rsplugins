<https://developer.runescape.com/rs/> (captured 2026-10-20). They're for context, not a copy;
check the official pages when details matter.

## Notes for the API dump script

- The site is built with Zensical (an mkdocs-material–style generator). Every page's content is
  in `<article class="md-content__inner md-typeset">`.
- **`https://developer.runescape.com/rs/search.json`** is the full-text search index: ~1300
  entries of `{location, level, title, text(HTML), path}`, one per heading section across every
  page. It's probably the easiest single source to dump.
- API reference pages live under `core/`, `game/` (with `config/`, `entity/`, `list/`), `math/`,
  `ui/` (with `decorative_components/`, `interactive_components/`, `layout_components/`) and
  `audio/`. The guide pages are everything else.
- `sitemap.xml` is empty. Get the page list from the nav links in any page, or from `search.json`.
- Policy: only scrape the **public** site. See the AI policy in [guidelines.md](guidelines.md).
