# RS3 Client Plugin API — Overview

Distilled from the official docs at <https://developer.runescape.com/rs/getting-started.html>
(captured 2026-10-20). This is our own summary; the official site is the source of truth.

## What it is

- Jagex's official plugin system for the RuneScape 3 game client. Plugins are **Lua 5.4.8**
  scripts that the client embeds and runs. Make sure any external Lua advice you use works on 5.4.
- Plugins can read game state (configs, nearby entities, player stats, vars, inventories, chat…),
  draw UI and world overlays, react to events, store data locally, play audio, and, with
  permission, make HTTP requests.
- Plugins **cannot** automate gameplay or send actions to the server. What's allowed is a
  moderation policy, not just an API limit: see [guidelines.md](guidelines.md).

## Lifecycle of a plugin

```
write code ──► test on the plugin BETA world (dev_plugins/ folder, console commands)
          ──► upload zip to Mod.io ──► Jagex manual moderation (code review + test run)
          ──► approved: available to players in the in-client plugin browser
```

- Unmoderated plugins only run on the **plugin beta / developer environment**. Its character
  progress is kept separate from the live game, so testing can't give anyone an advantage.
- Players get plugins from **Mod.io** (<https://mod.io/g/runescape>). Each new version of an
  approved plugin is moderated again; the old version stays live meanwhile.
