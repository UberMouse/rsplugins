# Game chat that scripts/recording-sanitise.py keeps in a fixture: a ChatMessage with no sender
# keeps its text only if the whole text matches one of these lines. Any other game text is
# redacted to "<redacted:N chars>".
#
# A pattern must not be able to match another player's name, since game messages name players
# ("Bob has logged in."): only fixed text, numbers ([0-9,]+), colour tags (<col=[0-9A-Fa-f]{6}>)
# and alternations of known names (tracks, achievements, areas). The script refuses to load a
# line with a free-form slot: a . or \w \W \s \S \d \D \b \B outside a class, any class but
# [0-9,] and the hex inside the whole token <col=[0-9A-Fa-f]{6}> (names like Facade are spelled
# in hex letters), + * or {n,m} after anything but [0-9,], a quantifier after that token, and
# any (? form but (?:, (?P<name>, lookarounds and (?#...), which rules out inline flags and
# conditionals. Each line is a Python regex anchored as a whole: ^ first, $ last, no other ^
# or $, and any | inside a group, as in (?:a|b). Blank lines and lines starting with # are
# skipped.

# Thieving: pickpocketing
^You pick the target's pocket\.$
^<col=[0-9A-Fa-f]{6}>Your pickpocket target becomes aware of your presence\.$
^You fail to steal from the target\.$
^You've been stunned\.$
^You're stunned\.$

# Money pouch and currency pouch
^[0-9,]+ coins have been (?:added to|removed from) your money pouch\.$
^The following has been added to your currency pouch: [0-9,]+ x (?:Spooky tokens)\.$

# Daily Horseclan confections
^<col=[0-9A-Fa-f]{6}>While skilling, you find your daily Horseclan confections\.$

# Music unlocks, by track name
^<col=[0-9A-Fa-f]{6}>You have unlocked a new music track: (?:The Duke)\.$

# Achievements and area task sets, by achievement and area name
^Congratulations! You have completed: (?:'Window Shopping' - Browse Lumbridge's general store)\.$
^<col=[0-9A-Fa-f]{6}>You've just completed your first achievement in the following area task set: (?:Beginner|Easy|Medium|Hard|Elite) (?:Lumbridge)$
^<col=[0-9A-Fa-f]{6}>Go to the 'Area Task Sets' tab of the 'Achievements' interface to find out about the other tasks in the set and the rewards for completing them\.$
